## skill-taskwarrior

Manages personal tasks with the Taskwarrior CLI (`task`), pairing each task with `description.md` and `definition-of-done.md` files under `~/.my-tasks/<task-uuid>/`. Covers creating tasks, reading/updating their description and definition of done, starting/stopping time tracking, and marking tasks done.

See [skill-taskwarrior/SKILL.md](skill-taskwarrior/SKILL.md) for full details.
